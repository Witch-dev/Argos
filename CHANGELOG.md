# Changelog

One line per real change or fix across both repos (Apollon code and Argos planning), newest first. It answers "have we hit this before, and when?" The detail lives where each line points.

**Format:** `- YYYY-MM-DD — What changed → where the detail is`. The pointer is a spec (`specs/x.md`, for features), a bug file (`bugs/x.md`, for bugs), another planning file, or an Apollon commit (`Apollon a1b2c3d`) for a small fix with no other record, in which case the commit message carries the detail. Add the line at the top of the current month when the work is finished. No paragraphs here: the detail goes in the spec, the bug file or the commit message.

**Older entries:** until 2026-10-07 entries were full paragraphs. Their full text is in `changelog/2026-09.md` and `changelog/2026-10.md`. Lines without a `→` pointer have their full text there.
