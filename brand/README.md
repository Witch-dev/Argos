# Brand sources

Source artwork kept here so it's backed up without being published: anything in `Apollon/web/public` ships with every build and is downloadable from the site.

- `winged-words-logo.png`: the winged-dog logo at 1610×977, the largest copy there is. Its background is **not** transparent: the grey-and-white checkerboard is painted in, so cut the logo out by colour (keep the pixels where red is well above blue) before using it on anything. `Apollon/web/public/og-image.png` was made this way on 2026-10-19 (`specs/landing-page.md`). The site's own `logo-mark.png` is only 276 px wide.

The avatar sheets live in `Apollon/web/art-sources/`.
