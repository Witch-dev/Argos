# Pass: overdrive

Push one interaction past the usual limits so it feels extraordinary. On Winged Words that rarely means visual effects; it means how something **feels**: a dialog that grows out of the button that opened it, a search that filters a 2,000-book shelf without a flicker, a list reorder that tracks the finger perfectly, an optimistic save that never hesitates.

This pass has the highest chance to misfire, so:

1. **Propose 2–3 directions before writing any code**, each with what it would look and feel like and its trade-offs (browser support, performance cost, complexity, accessibility). Put the descriptions inside the options the user chooses between.
2. **Build only the direction the user picks.**
3. **Verify in the browser, not from code:** timing, easing and smoothness on a throttled phone, with reduced motion, by keyboard. Iterate until it is genuinely good.

## Fit
- Operate screens: the "wow" is speed, continuity and certainty, never decoration. A particle effect on a settings page is embarrassing; instant, animated, optimistic saves are not.
- The landing page (Persuade) may carry one sensory moment, still built on the cream page and the shelf.
- Everything in DESIGN.md "Motion" and the quality floor still applies. Then `polish`.
